## 48.1 Why these were skipped, and why they still matter

The engine chapters chased *behaviour* — what the game does at runtime. These files are mostly *configuration*
and *content*, so they slipped past. But by the project's own standard — "comb every file" — they are exactly
the kind of thing that must be accounted for, and a couple hold genuine value: `shopping.dat` is the data
behind [C30](../C30-Gameplay-Managers/C30-Gameplay-Managers.md)'s `CShopping` runtime (the chapter sized the
560-item ledger; this is what fills it), `clothes.dat` is a small rule *language* (not just a table), and
`polydensity.dat` is the only binary file in the set and had never been opened. The rest are load lists and
alternate-copies of things already documented — but "documented as a duplicate of X" is still coverage, and
that is the job here.

## 48.2 What the sweep confirms about the format families

The 13 files fall into the format families this encyclopedia already knows:

- **IDE/load-list text** ([C11](../C11-IDE-And-IPL/C11-IDE-And-IPL.md)): `default.dat`, `gta_quick.dat`,
  `default.ide`, `txdcut.ide`, `animviewer.dat` — line-oriented `KEYWORD args` config.
- **Column tables** ([C15](../C15-Timecycle/C15-Timecycle.md)/[C24](../C24-Surfaces/C24-Surfaces.md) style):
  `timecycp.dat` (identical columns to `timecyc.dat`), `shopping.dat` (nested `section` blocks).
- **Rule mini-languages**: `clothes.dat` (`SETC`/`HIDE`/`IGNORE`/`EXCLUSIVE` verbs), `furnitur.dat`
  (`GROUP`/`SUBGROUP`/`ITEM`).
- **Geometry tables**: `water1.dat` (quad vertices, like `water.dat`).
- **Binary array**: `polydensity.dat` alone — a flat `uint32[72005]` grid.

So the sweep does not introduce a new format; it confirms the retail data folder is built from the handful of
grammars the earlier chapters decoded, plus one binary grid. That is itself a finding: **`data/` is
format-complete** against the encyclopedia — every remaining file parses with knowledge already in hand.

  from the IDE/column/rule/geometry families already decoded plus one binary array.
