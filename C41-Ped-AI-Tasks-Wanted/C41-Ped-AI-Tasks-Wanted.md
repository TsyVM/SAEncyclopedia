## 41.1 Why this cracks the "CTask tail"

Across C27–C37 the classifier kept bottoming out on the same residue: an "unstructured `CTask*`/`CEvent*`
one-method tail" it could not attribute, because none of those classes had been given structure. The reason
is architectural — `CTask` is not one class but a **hierarchy of hundreds** (`CTaskSimple*`, `CTaskComplex*`,
one per behaviour: walk, enter-car, aim, flee, …), each tiny. You cannot size "CTask" the way you size a
pool. But you *can* size the thing that owns them all — `CTaskManager` — and that is the key that turns the
tail from an amorphous mass into a structured tree with five labelled slots. This chapter does that, and in
doing so gives the C33/C37 classifier a new signature (the task-manager offsets) to attribute the tail
against in a future pass.

## 41.2 The shape of ped AI, in one paragraph

Every `CPed` owns a `CTaskManager` ([C41.1](01-the-task-tree.md)). The manager holds five **primary** task
slots in strict priority order — a physical response (ragdoll/impact) preempts an event response, which
preempts the ped's standing primary task, which preempts its default idle — plus six **secondary** slots for
things that run *alongside* the primary (attacking, ducking, talking, facial animation). Events
(`CEvent*` — being shot at, seeing a crime, a nearby explosion) are what write into the event-response
slots. When *the player* is the criminal, the [C41.2](02-the-wanted-system.md) `CWanted` system tallies
**chaos points** per crime and crosses the fixed star ladder; the wanted level then decides
[C41.3](03-dispatch-and-roadblocks.md) **who is dispatched** (street cops up through the Army) and whether
**roadblocks** spawn. So the AI is one uniform machine — a prioritised task tree fed by events — with the
wanted system as the specific event-source that turns the whole police force into tasks aimed at you.

## Key takeaways

- A ped's behaviour is a **task tree** owned by `CTaskManager` (**`0x30` bytes**: 5 primary + 6 secondary
  task pointers + the ped), with the primary slots forming a strict **priority ladder**.
- The **wanted system** is a fixed **chaos-point ladder** — 50/180/550/1200/2400/4600 → 1–6 stars, capped at
  9200 — proven cold from the six `cmp` immediates in `UpdateWantedLevel`.
- The wanted level drives **dispatch escalation** (cops → SWAT → FBI → Army → helis) and up to **325**
  roadblocks — the police response is just tasks aimed at the player.
