# Chapter 36 — CScriptsForBrains: the Attractor-Brain Table

> **Goal of this chapter:** decode the "script brain" system — the mechanism that attaches an
> external/streamed mission script to a *class of world object or ped* by model id, so it fires when the
> player comes near (a shop clerk's dialogue, a gang attractor, a scripted prop). Its state is a fixed
> **70-slot × 20-byte table** held in the manager object, a free slot marked by a `0xFFFF` id — the
> in-memory registry that sits between [C31.3](../C31-Streaming-Slot-Tables/03-cstreamedscripts.md)'s streamed

## Why this chapter

A "script brain" is San Andreas's mechanism for making the world *reactive without a mission running*: a
short external script is registered against a model id or a name, and the engine runs it when the player
approaches an instance of that model. It is how a barber's chair offers a haircut, how gang members react in
their territory, how scripted props behave — all without the resident `main.scm` spending an opcode on them.

`CScriptsForBrains` is the registry for that system, and structurally it is a clean fixed table: **70 entries
of 20 bytes**, the count proven three independent ways and the record's free-slot marked by the same `0xFFFF`
"no model" sentinel the pickup and model systems use. Like [C32](../C32-CRunningScript-Object/C32-CRunningScript-Object.md)'s
`CRunningScript`, the table is embedded in its manager object rather than at a fixed global, so this chapter
reads it `this`-relative — the offsets are certain, the object's own address is supplied by its callers.

The chapter also sits at a junction the encyclopedia has been circling: it consumes
[C31.3](../C31-Streaming-Slot-Tables/03-cstreamedscripts.md)'s 82-slot streamed-script table (a brain's code
is a streamed script) and produces [C32](../C32-CRunningScript-Object/C32-CRunningScript-Object.md)'s
`CRunningScript` threads (when a brain fires, it starts a script). Between the file-level script model
([C18](../C18-SCM-Script/C18-SCM-Script.md)) and the running-thread object (C32), this is the *trigger* layer.
