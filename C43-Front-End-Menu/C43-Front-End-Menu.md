## 43.1 A menu with no menu file

Some engines describe their menus in a data file you could edit. San Andreas does not — the entire front-end
is a `static tMenuScreen aScreens[]` array compiled into the executable's `.data` at `0x8CE008`. That is a
finding in itself: there is nothing to extract from the disc for the menu layout because the layout *is* the
program. But because it is a plain array of fixed-size structs, it decodes exactly like any of this project's
data tables — a base, a stride, a count — and this chapter reads all three from the bytes. The 44 screens run
from `Stats` (`FEP_STA`) through the settings pages to the `Pause` screen (`FET_PAU`), each one a self-
contained record of what it shows and where its options lead.

## 43.2 The whole menu, in one paragraph

`CMenuManager` holds a **current screen index** (`m_nCurrentScreen`) and a **current item index**
(`m_nCurrentScreenItem`). To draw a frame it indexes `aScreens[m_nCurrentScreen]` — an `imul × 0xE2` — to get
the screen, draws its title (a [C19](../C19-GXT-Text/C19-GXT-Text.md) GXT key) and each of its up-to-12 items
(each item's label is *also* a GXT key), highlighting item `m_nCurrentScreenItem`. Pressing up/down changes
the item index; pressing enter reads that item's **action** and **target screen** and either performs the
action (toggle a setting, start a game) or navigates — sets `m_nCurrentScreen = item.m_nTargetMenu`. Pressing
back returns to the screen's `m_nParentMenu`. That is the whole front-end: a table walk over `aScreens`, with
GXT for text and [C23](../C23-Fonts-HUD/C23-Fonts-HUD.md) for glyphs. Every screen you have ever seen in the
pause menu is one of the 44 rows this chapter decodes.

## Key takeaways

- The front-end is a **hardcoded table**, `aScreens[44]` @`0x8CE008`, not a data file — the layout is baked
  into the executable.
- Each screen is a `0xE2`-byte `tMenuScreen` that tiles as `title[8] + parent + startEntry + 12 × 0x12-byte
  items`; the strides are proven cold (`imul 0xE2`, item `×9 ×2`).
- The menu is a thin renderer over [C19](../C19-GXT-Text/C19-GXT-Text.md) (every label is a GXT key) and
  [C23](../C23-Fonts-HUD/C23-Fonts-HUD.md) (the fonts + `fronten*.txd` sprites); navigation is the
  parent/target screen indices.
